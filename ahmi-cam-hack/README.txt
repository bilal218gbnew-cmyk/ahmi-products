AHMI CAM HACK

This is a consent-based Progressive Web App (PWA). Camera, microphone and location work only after the user presses the relevant control and grants browser permission. It does not remotely access another person's device or send captured data to a Telegram bot.

FREE HOSTING
The app files are in the ahmi-cam-hack/ folder inside the existing ahmi-products repository. If GitHub Pages is already enabled for this repository and publishes from the main branch root, the app should be reachable at:
https://bilal218gbnew-cmyk.github.io/ahmi-products/ahmi-cam-hack/

If that URL gives a 404, enable GitHub Pages in repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save. Allow a few minutes for deployment.

Install on Android: open the HTTPS app URL in Chrome, open the three-dot menu and choose Install app / Add to Home screen.

IMPORTANT: HTTPS is required by browsers for camera, microphone and location permissions. This is a web app/PWA, not a native APK.
